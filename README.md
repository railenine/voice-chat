## 🌟 Ключевые особенности RVxis

- **🎙️ Студийный аудиотракт**:
  - Аппаратная фильтрация микрофона на уровне WebRTC.
  - Нейросетевая модель **RNNoise** в `AudioWorklet` (WebAssembly) для изоляции голоса от кликов мыши, клавиатур и шума вентиляторов.
  - Аналоговый срез 90 Гц (High-Pass), речевой Peaking EQ 3200 Гц и High-Cut 12 кГц.
  - Мягкий экспоненциальный нойз-гейт (Downward Expander с атакой 10 мс и удержанием 400 мс).
  - Режим Opus DTX (`usedtx=1`) для абсолютной тишины в паузах.
- **🖥️ Демонстрация экрана высокой четкости**:
  - Плавная трансляция экрана **1080p @ 60fps** на базе выделенного **LiveKit WebRTC SFU**.
  - Режим «Картинка в картинке» (PiP Overlay) и полноэкранный плеер с сохранением доступа к чату и панели участников.
- **👥 Предсказуемое масштабирование комнат (MAX_ROOM_PEERS = 12)**:
  - Прямые peer-to-peer соединения между всеми участниками комнаты (Full Mesh).
  - Четкий предел емкости P2P-сети: до 12 участников в комнате (66 соединений).
  - Протокольное отклонение 13-го участника с кодом `room_full` и информативным баннером для предотвращения перегрузки сети.
  - Бесшовное переподключение (Ghost Socket Eviction) при сетевых сбоях.
- **🔊 Изолированная регулировка громкости**:
  - Индивидуальная настройка громкости каждого собеседника (от 0% до 200% с динамическим компрессором-лимитером).
  - Настройки привязаны строго к `peerId` и сохраняются при смене никнейма собеседником.
- **🛡️ 100% Конфиденциальность (RAM-Only)**:
  - Никакой регистрации, учетных записей, номеров телефонов или баз данных.
  - Звонки и комнаты создаются на лету по 6-значному коду.
  - Текстовый чат живет исключительно в оперативной памяти и очищается при закрытии комнаты.
- **🌐 Надежная связь (с VPN и без)**:
  - Собственный сервер **Coturn STUN/TURN** на `rvxis.site` (UDP, TCP, TURNS TLS 5349) для обхода Symmetric NAT и работы через VPN.
  - Динамические эфемерные учетные данные TURN на базе HMAC-SHA1.
  - Автоматическое самовосстановление (ICE Restart) при смене сети без разрыва сессии.
- **💻 Кроссплатформенность**:
  - **Desktop**: Нативное настольное приложение Windows / macOS / Linux на базе **Tauri v2** с безрамочным окном, глобальными горячими клавишами (Push-to-Talk, Mute, Deafen) и двойной системой безопасного автообновления: NSIS с Ed25519 Minisign + автономный Portable `RVxis.exe` с верификацией SHA-256 и атомарным откатом (rollback).
  - **Web & Mobile**: Отзывчивый интерфейс в стиле Glassmorphism Dark (`#020617`), поддержка мобильных браузеров iOS Safari и Android Chrome с удержанием фонового аудио (Screen WakeLock & MediaSession API).

## 🚀 Быстрый старт

### Требования
- **Node.js** 20.0+
- **Rust** и **Cargo** (для сборки десктопного клиента Tauri)

### 1. Локальная разработка (Веб)
```bash
# Клонирование репозитория
git clone https://github.com/railenine/voice-chat.git
cd voice-chat

# Установка зависимостей
npm install

# Запуск в режиме разработки с HMR
npm run dev

# Проверка типов и тестов (Unit, HTTP & WS Integration на реальных модулях)
npm run typecheck
npm test

# Запуск стресс-тестирования 12-пировой P2P-сетки (72 проверки)
npm run test:mesh
```
Приложение откроется по адресу `http://localhost:5173`.

### 2. Запуск локального продакшн сервера
```bash
npm run build
npm start
```
Сервер будет доступен по адресу `http://localhost:3000`.

### 3. Запуск десктопного клиента (Tauri v2)
```bash
npm run desktop:dev
```

## 🖥️ Деплой на VPS

### Вариант 1: Docker Compose (рекомендуется)
```bash
# На вашем сервере (Ubuntu 20.04+)
git clone https://github.com/railenine/voice-chat.git
cd voice-chat

# Запуск контейнера в фоне
docker-compose up -d

# Проверка статуса
docker-compose ps
curl http://localhost:3000/health
```

### Вариант 2: PM2 / Systemd
```bash
npm install
npm run build
pm2 start server/index.js --name rvxis
pm2 save
pm2 startup
```

Полная конфигурация Nginx Reverse Proxy, LiveKit и Coturn приведена в **[ARCHITECTURE.md](ARCHITECTURE.md#10-развертывание-и-конфигурация-на-vps)**.

## 📦 Релизы и версионирование

Для выпуска новой версии используется автоматизированный скрипт:
```bash
# Синхронизация версий во всех конфигурационных файлах и создание коммита/тега:
node scripts/bump-version.js 0.1.12 --push
```
GitHub Actions автоматически соберет кроссплатформенные бинарные файлы, подпишет их ключом Ed25519 и сгенерирует манифест автообновления `latest.json`.
